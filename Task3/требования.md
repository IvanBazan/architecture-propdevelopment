
# Список требований, которым должны удовлетворить внешние интеграции: 

## Взаимодействие между системами предприятия и внешней платформой:

##### целевые user flow:

0. Общие:
   1. Добавление пользователя-администратора квартиры 
   2. Удаление пользователя-администратора квартиры

1. Домофон:
   1. Администрирование (добавление/удаление) пользователя в разрешенные к проходу в квартиру
   2. Добавление биометрического аутенификатора для пользователя с разрешенным доступом

2. Шлагбаум
   1. Добавление OCR аутенификатора для машины с разрешенным проездом

## Требования к безопасности

- Отсутсвие персональной информации в БД системы предоставляющей доступ и системы распознавания
- Отсутсвие персональной (незашифрованной, необезличенной) информации в АПИ контрактов взаимодействия

## Протоколы аутентификации и авторизации

- В системах управления домофоном и шлагбаумом должны быть REST API методы добавление/удаления пользователя-администратора квартиры.  
  - для взаимодействия используем TLS
  - идентификатор квартиры должен быть зашифрован
  - индентификатор пользователя-администратора тоже должен быть зашифрован

- Аналогичные требования должны распространяться на методы добавления биометрических аутенификаторов для доступа в квартиры и OCR аутентификаторов для распознавания номерных знаков
